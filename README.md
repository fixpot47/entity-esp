# EntityESP

Standalone Fabric client mod for Minecraft **26.3**.

Press **F8** to open the **EntityESP** menu and independently toggle:

- **PlayerESP** — highlights other players through blocks.
- **MobESP** — highlights living non-player entities through blocks.
- **ChestESP** — highlights chests and many other storage/container blocks through blocks, plus chest boats and storage minecarts.

The three toggles are saved in `config/entity-esp.properties`.

## Requirements

- Minecraft 26.3
- Fabric Loader
- Fabric API
- FixLib 2.2.0+26.3
